# oktOpus Safety Team – nyilvános arculati fájlok

Az oktOpus Multimédia Intézet elsősegély- és biztonságtechnikai csapatának nyilvános fájljai.
A fájlok a GitHub Pages-en keresztül érhetők el, pl.:
https://oktopus-safety-team.github.io/assets/email/jelveny.png

## Mappák
- `email/` – az e-mail-aláírás képei (jelvény, négyzetes jelvény)
- `logo/` – logóváltozatok: fekvő logó sötét és világos háttérre (PNG), jelkép (SVG, PNG)
- `qr/` – QR-kódok

## Szabályok
- A már kiadott fájlokat **nem nevezzük át** – az aláírások és QR-kódok a fájlnévre hivatkoznak.
- Frissítésnél ugyanazzal a névvel cseréljük le a fájlt.
- Fájlnév: kisbetű, ékezet nélkül, kötőjellel.
- Ide csak nyilvános anyag kerülhet. Személyes adat, tagokról készült fotó, belső dokumentum nem.

A fájlok nem szabad felhasználásúak; minden jog fenntartva.
